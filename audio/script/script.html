Tertius audio: recording script

All 1,287 words in learning order, as the app shows them, in 13 takes of up to 100.
  1. As for Telamon: a quiet room, about a hand's width from the microphone, mono WAV.
  2. Aim for the loudest words near −12 dBFS.
  3. Start each take with 2 seconds of silence. Say each word once, then pause about 1½ seconds. Don't say the numbers.
  4. Where a line has several forms (οὐ, οὐκ, οὐχ), read them all, with only a short break between them.
  5. If you misread a word, stop the take and start it again: a take is only a few minutes long.
  6. Save each take in this audio folder under the name shown in its heading (take_01.wav …).
  7. The 3 highlighted words carry a note on how to read them.
