# NT Greek trainer (Expo app)

A Telamon-style vocabulary trainer built on Metzger's *Lexical Aids* (1946), Souter's *Pocket Lexicon* (1917), and the MossMethod list.

- **Path**: Metzger's frequency tiers and root families broken into short units (study, then recall).
- **Review**: FSRS spaced repetition (ts-fsrs) with Again / Hard / Good / Easy.
- **Word pages**: Metzger gloss, family, Moss entry, and Souter's full entry.
- **Search**: Greek, Latin-keyboard transliteration, or English.
- **Settings**: count Moss words as already known; erase progress.

Progress is stored on the device (AsyncStorage).

## Run

    npm install
    npx expo start          # press w for web, or scan with Expo Go

## Data

`assets/data/lexicon.json` is generated by `../scripts/build_app_data.py` from `../data/app/lexicon.json`.

## Web preview build

    ./scripts-preview.sh

Exports to `dist/` and renames `_expo/` to `expo-static/` (artifact hosting reserves `_` paths).
